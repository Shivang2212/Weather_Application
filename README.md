# 🌤️ Weather Application

A simple and responsive **Weather Application** built using **HTML, CSS, and JavaScript**. The application allows users to search for a location and view its current weather information through a clean and user-friendly interface.

## 🚀 Features

* 🌍 Search weather by city/location
* 🌡️ Display current temperature
* ☁️ Show weather conditions
* 💨 Display additional weather information
* 📱 Responsive and user-friendly design
* ⚡ Dynamic weather data using JavaScript
* 🎨 Clean and simple interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and dynamic weather data
* **Weather API** – Fetching real-time weather information

## 📂 Project Structure

```text
Weather_Application/

```

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Shivang2212/Weather_Application.git
```

### 2. Open the project folder

```bash
cd Weather_Application
```

### 3. Run the application

Open `Weather.html` in your web browser.

You can also use **Live Server** in Visual Studio Code for a better development experience.

## 🔑 API Configuration

If the project uses a weather API, add your API key inside `Weather.js`.

For example:

```javascript
const apiKey = "YOUR_API_KEY";
```

Replace `YOUR_API_KEY` with your actual API key.

> ⚠️ For public repositories, avoid exposing a private API key directly in your source code. Use environment variables or another secure configuration method when possible.

## 🖥️ Application Workflow

```text
User enters city
       ↓
JavaScript sends request to Weather API
       ↓
API returns weather data
       ↓
JavaScript processes the response
       ↓
Weather information is displayed
```
